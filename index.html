About the Engine — Honest Technical Notes

            
Real execution: Every statement you run is executed for real by SQLite 3.x compiled to WebAssembly via sql.js inside your browser. There is no server and no network round-trip.

            
MySQL compatibility: Your MySQL syntax is translated to SQLite before execution. The Compatibility notes panel shows both versions. We never pretend a MySQL server is running.

            
Persistence: After each successful write we export the SQLite binary with db.export() and store it in IndexedDB. On reload we restore it. If IndexedDB is blocked, we fallback to localStorage (base64). Export/Import is always available.

            
    
              
  • Foreign keys: Enforced via PRAGMA foreign_keys = ON at startup. Invalid FK inserts fail with a real error.
    • 
              
  • Multiple databases / USE: Emulated as a logical namespace. SHOW DATABASES returns configured names; USE db sets a prefix. No real ATTACH is needed for the demo, but the layer documents the limitation.
    • 
              
  • Limitations vs MySQL:
                
      
                  
    • Strict typing: SQLite is dynamically typed; types are affinities.
      • 
                  
    • No stored procedures / triggers (limited), no users/GRANTS/permissions.
      • 
                  
    • Some functions differ: we polyfill NOW(), IFNULL, CONCAT, DATE_FORMAT subset, YEAR/MONTH.
      • 
                  
    • AUTO_INCREMENT mapped to AUTOINCREMENT with INTEGER PRIMARY KEY.
      • 
                  
    • ENUM becomes TEXT + CHECK.
      • 
                
    
              
    • 
            

          

          

            
How to Run Locally

            
Why a static server is required: Browsers block fetch for .wasm when opening file:// due to CORS and MIME rules. sql.js loads sql-wasm.wasm via fetch; it will fail on file://.

            
Serve the folder over HTTP. Any static server works. Pick one:

            
npx serve .
# or
python3 -m http.server 8080
# or
php -S localhost:8080
# or
npx http-server -p 8080

            
Then open http://localhost:8080 (or the printed URL). No build step.

            
Browser requirements: modern evergreen with WebAssembly, IndexedDB, ES modules (Chrome 90+, Firefox 90+, Safari 15+, Edge 90+).

  ↑  engine.js  — single DB, exec/run/introspect/persist, MySQL→SQLite translation, PRAGMA FK ON
  ↑  driver.js  — fake mysql2/promise pool/connection, ? binding, [rows,fields], latency slider

MySQL → SQLite translation rules

            
    
              
  • AUTO_INCREMENT → AUTOINCREMENT + force INTEGER PRIMARY KEY
    • 
              
  • Strip ENGINE=InnoDB, DEFAULT CHARSET=…, COLLATE=…
    • 
              
  • Backticks `id` → "id"
    • 
              
  • Types: INT→INTEGER, VARCHAR→TEXT, DECIMAL/FLOAT→REAL, DATETIME→TEXT, BOOLEAN→INTEGER, ENUM→TEXT+CHECK
    • 
              
  • NOW()/CURRENT_TIMESTAMP → datetime('now')
    • 
              
  • CONCAT(a,b) → (a || b), IFNULL kept, YEAR() → strftime
    • 
              
  • LIMIT x, y → LIMIT y OFFSET x
    • 
              
  • ON DUPLICATE KEY UPDATE → ON CONFLICT DO UPDATE SET
    • 
              
  • SHOW/DESCRIBE rewritten to sqlite_master/PRAGMA queries
    •

// 1 — Transactional insert
const conn = await pool.getConnection();
try{
  await conn.beginTransaction();
  const [r] = await conn.execute('INSERT INTO customers (name,email) VALUES (?,?)',['Ada','ada@example.com']);
  await conn.execute('INSERT INTO orders (customer_id,total,status) VALUES (?,?,?)',[r.insertId,149.99,'paid']);
  await conn.commit(); console.log('committed', r.insertId);
}catch(e){ await conn.rollback(); console.error(e.message);} finally{ conn.release();}

            
// 2 — Prepared SELECT
const [rows] = await pool.query('SELECT c.name, o.total FROM customers c JOIN orders o ON o.customer_id=c.id WHERE o.status=?',['paid']);
console.table(rows);

            
// 3 — Error handling (FK violation)
try{
  await pool.query('INSERT INTO orders (customer_id,total) VALUES (?,?)',[9999, 10]);
}catch(e){
  console.error(e.code, e.sqlMessage);
}
